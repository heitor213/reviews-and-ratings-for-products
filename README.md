# Модуль отзывов и рейтингов товаров/курсов

Учебный проект по МДК 02.02 «Инструментальные средства разработки программных модулей».

## Стек
- Python 3.10+, PyQt6, pyodbc
- MS SQL Server (8 таблиц)
- Git + GitHub, Kanban (Trello)

## Структура
src/ — исходный код (db / logic / ui)
tests/ — unit-тесты
docs/ — документация, UML, ТЗ

## Быстрый старт
1. Выполнить `sql/init_db.sql` в SSMS
2. `pip install -r requirements.txt`
3. `python main.py`
